# 项目专属智能体规则 (Agent Project Rules)

这些规则仅适用于当前项目工程，在执行任何相关任务时必须严格遵守。

## 1. 文档变更与版本追溯规范
- **禁止原地覆盖**：在修改任何需求、设计、产品逻辑或解决方案等相关文档时，**绝对禁止**使用原地覆盖（Overwrite）的方式修改原文件。
- **创建新版本文件**：必须将修改后的内容创建为一个新的文件。新文件命名必须体现版本迭代（如：在原文件名后追加 `_v2`、`_v1.1` 或当前日期标识）。
- **强制记录变更履历**：在生成的新文档头部（标题下方），必须增加一段醒目的“变更履历（Revision History）”，其中必须包含：
  - **修改日期**
  - **修改执行人**（如：AI Agent）
  - **核心变更点**（分点简述本次改动了哪些业务逻辑或新增了哪些模块）
- **适用范围排除**：以下路径下的所有文件**豁免**本节版本追溯规范，允许直接原地更新，无需创建新版本文件，也无需记录变更履历：
  - `.agents/` 目录及其所有子目录（包括 `skills/`、`AGENTS.md` 本身等工程基础设施配置文件）
