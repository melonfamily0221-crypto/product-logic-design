# 业务系统产品逻辑设计

本项目用于维护和管理业务系统的产品逻辑设计资产，包括核心业务主链路、系统解决方案、领域数据实体模型，以及配合 AI Agent 的自动化文档生成和推演库。

## 目录结构

- **`docs/`**
  核心产品设计文档与资产的统一存放目录。由自动化工作流生成的各类产物按阶段存放：
  - `solution/`：系统原始解决方案（如 `解决方案V0.2.md`）。
  - `domain-model/`：领域数据实体清单。
  - `logic-asset/`：三层解耦式的核心聚合根逻辑资产说明书。

- **`.agents/`**
  当前工程专属的智能体 (Agent) 规则与自定义技能库。包含了通过 AI 辅助产品逻辑设计自动化的核心能力：
  - **`skills/domain-driven-extract`**：领域驱动提取技能。支持从复杂的解决方案文档中，自动化提取出所有的业务数据实体及生命周期状态。
  - **`skills/logic-asset-generate`**：逻辑资产说明书生成技能。可根据提取的领域实体清单，基于标准化模板批量生成每一个核心聚合根的《逻辑资产说明书》。

## AI 协同与自动化工作流

本项目集成了高度定制化的 AI 技能，您可以随时在对话中触发以加速设计工作：

1. **提取领域模型**：
   向 AI 输入指令 *"领域驱动提取"*。AI 会解析原始需求/解决方案，输出标准的《领域实体清单》。
   
2. **批量沉淀逻辑资产**：
   输入指令 *"批量生成逻辑资产"*。AI 将自动对核心聚合根进行推演，生成包含状态机、E-R图、字段校验规则的三层解耦式《逻辑资产说明书》。

## 规范与约定 (AGENTS 规则)

本项目中的文档协作需严格遵守以下规则：
- **禁止原地覆盖**：在修改核心设计方案或逻辑资产文档时，不可直接覆盖原文件，须创建包含新版本标识（如 `_v2`、`_v1.1` 或当前日期）的独立副本。
- **强制变更履历**：所有新文档的头部必须包含明确的**变更履历 (Revision History)** 表格，记录修改日期、执行人（如 AI Agent）及核心变更点。
- **豁免范围**：`.agents/` 目录及其所有子目录属工程基础设施配置文件，**允许原地更新**，无需版本追溯。
